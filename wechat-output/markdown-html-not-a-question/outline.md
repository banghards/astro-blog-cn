# 提纲

## 选题

Markdown 和 HTML 的争论本质上问错了问题。真正值得回答的是：生产端用什么，消费端用什么。

## 结构

1. 引入：争论之所以吵起来，是因为两边在回答不同问题。
2. Markdown 端：轻、快、可 diff、token 省，适合生产。
3. HTML 端：可视化、交互、结构化阅读，适合消费。
4. 真结论：不是替代，是分工。
5. 工作流：md 生产，HTML 消费。
6. 关键能力：需要的是格式转换闭环，而不是站队。

## 配图

1. 封面：参考原图的对照感，但表达“分工”而不是“对立”。
2. Markdown 生产端：规则、知识、文稿、diff、低 token。
3. HTML 消费端：原型、解释器、仪表盘、交互展示。
4. 工作流：Markdown 输入，HTML 输出，中间由 AI 负责转换。
