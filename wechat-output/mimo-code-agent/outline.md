# 提纲

## 选题

MiMo Code 真正值得看的是长程 Agent 架构，而不是单纯的 benchmark 或“国产替代”叙事。

## 结构

1. 引入：小米开源 MiMo Code，热点之外看架构。
2. 定义：终端原生 AI 编程 Agent，基于 OpenCode。
3. 持久记忆：MEMORY、checkpoint、notes、progress。
4. 子智能体：主 Agent、subagent、judge model 分工。
5. Compose：规划、执行、审查、TDD、调试、验证、合并。
6. dream/distill：历史记忆整理和重复工作流沉淀。
7. 开发者吸引力：MIT、一行安装、多 Provider、迁移友好。
8. 对比判断：benchmark 值得关注，但真正竞争在长程任务架构。
9. 项目链接和安装方式。
