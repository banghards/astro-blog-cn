# 提纲

## 选题

大多数人并不是没接触 AI Agent，而是一直把 Agent 当聊天机器人用，没有真正利用记忆、技能沉淀和 24/7 主动推进这几层能力。

## 结构

1. 引入：为什么很多人用了 Agent 还是觉得没那么强。
2. 核心误区：执行任务不是关键，记忆与经验沉淀才是关键。
3. Hermes 的本质：越用越懂你，本地记忆可见可控。
4. 分工关系：Hermes 适合日常与长期推进，Codex/Claude Code 适合深度工程。
5. 真正像员工的地方：Telegram、cron、goal、长期任务。
6. onboarding：第一天先让它认识你，而不是盲派任务。
7. 结论：不是没用 Agent，而是没真正让 Agent 上班。
