# 提纲

## 选题

Codex 真正盘活的关键，不是多聊几句，而是装对 Skill，让它拥有可复用的岗位 SOP 卡。

## 结构

1. 引入：为什么很多人手里的 Codex 只发挥了一半。
2. Skill 本质：不是 prompt 模板，而是岗位 SOP 卡。
3. 优先级：先装改变工作方式的元能力卡。
4. 资源源头：盯住官方和核心聚合仓。
5. 场景分类：按规划、CI/CD、测试安全、前端集成、生产力内容来装。
6. 安装策略：先用内置安装器，后谈批量和迁移。
7. 进阶玩法：组合、沉淀、迁移。
8. 结论：真正升值的是判断和工作流能力。

## 配图

1. 封面：Codex 从聊天框变成工程团队。
2. 核心技能卡：create-plan、gh-fix-ci 等元能力。
3. Skill 分类图：不同场景的能力卡矩阵。
4. 组合技：多张卡协同、团队沉淀、跨工具迁移。
