# 提纲

## 选题

Hermes 插件生态正在补 Agent 长期运行需要的底层能力：技能共享、结构化记忆、可观测工作台、企业级后端和运维面板。

## 结构

1. 引入：Hermes 不只是能跑任务，而是在长出生态系统。
2. Skill Registry：Agent 之间共享和安装技能。
3. Graphiti：记忆从线性记录升级成关系图谱。
4. Mnemosyne Dashboard：记忆从黑箱变成工作台。
5. YantrikDB：企业级向量和图数据库后端。
6. YantrikDB Dashboard：生产环境的可观测运维面板。
7. 结论：这些项目更像 Agent 操作系统的生态骨架。
