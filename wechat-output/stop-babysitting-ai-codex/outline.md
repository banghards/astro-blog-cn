# 提纲

## 选题

Codex 提效的关键，不是多聊几句，而是逐步减少那些你每次都要重复解释、重复搬运、重复触发的动作。

## 结构

1. 引入：为什么很多人用了 Codex 还是觉得累。
2. 插件：让 Codex 真的能动手。
3. Goal Mode：从微操切到定目标。
4. 自动化：让重复任务定时自己跑。
5. MCP + Obsidian：让 Codex 看见你的长期上下文。
6. Skills：把重复流程沉淀成 SOP。
7. 结论：先跑通一个最小闭环，不必一次配齐。

## 配图

1. 封面：人不再伺候 AI，而是让 Codex 接管重复劳动。
2. 插件 + Goal Mode：Codex 接上工具并围绕目标推进。
3. 自动化 + Obsidian：定时工作和个人知识库接入。
4. Skills：把常用流程沉淀成可复用能力。
