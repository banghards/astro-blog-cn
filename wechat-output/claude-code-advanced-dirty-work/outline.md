# 提纲

## 选题

Claude Code 的真正价值，不只是写代码，而是接管那些人类不想盯着看的上下文管理、长任务等待、审查、排查和验证脏活。

## 结构

1. 引入：AI 最强的不一定是写代码，而是处理脏活累活。
2. 上下文管理：主动 handoff，别迷信长对话。
3. 提示词瘦身：让热路径更轻，冷信息按需读取。
4. 高强度工作流：worktree、多标签、长任务并行。
5. 脏活外包：等待、日志、PR、DevOps 都适合 AI 接手。
6. 验证闭环：没有验证方式，AI 就无法真正自主。
7. 结论：掌握的不是 14 个技巧，而是一套分工方式。

1. 封面：AI 替人处理脏活累活的工程工作台。
2. 上下文管理：handoff 文档与新对话交接。
3. 并行工作流：worktree、标签页、长任务排队。
4. 验证闭环：测试、bisect、日志、确认结果。
