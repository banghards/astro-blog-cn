# Hermes 五套系统配图方案

文章类型：实操安装指南 + 系统搭建文

不适合的风格：
- 纯流程图
- 白板示意图
- 过强的赛博海报风
- 只讲抽象 AI 概念、没有“安装/工作台/系统感”的配图

这篇更适合的视觉方向：
- `安装指南型 editorial`
- `工作台 / 系统装配感`
- `轻信息设计`
- `低饱和技术杂志气质`

统一要求：
- 使用 `gpt-image-2`
- 中文公众号审美，不做夸张科幻
- 画面要体现“系统安装、目录归位、层级分工、入口与运行隔离”
- 少一些发光 HUD，多一些真实工作环境、模块、文件夹、卡片、布线、标签
- 配色以石墨灰、云雾白、深蓝灰、少量朱砂红点缀
- 构图干净，留出公众号排版呼吸感

四张图的分工：
1. 封面图：强调“装完 Hermes 之后，真正的差距在于把 5 套系统装对位置”
2. 五层结构图：不是流程图，而是“分层工作台 / 模块剖面”
3. 记忆层图：强调用户记忆、项目规则、长期记忆分别归位
4. 微信入口图：强调 Hermes 核心、微信网关、独立运行环境三者关系
