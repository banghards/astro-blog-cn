# Codex 从 0 到 1：普通人也能上手的智能体保姆级教程

Codex 不是只会回答问题的聊天机器人，而是能进入项目、读取文件、执行任务，并持续推动工作进展的数字员工。

普通人上手 Codex，不需要一开始就学命令行、MCP、Skill 或复杂模型参数。更稳的路线是从桌面版 App 开始，先让它完成低风险任务：整理文档、理解文件夹、分析 CSV、生成 HTML 页面，再逐步进入项目协作。

使用 Codex 时要区分普通对话和项目对话：一般问题用普通对话，涉及本地文件、项目、数据、代码、报错时用项目对话。

新手第一次实战可以从一句话生成一个简单 HTML 页面开始。不要期待一次完美，而是先做出来，再让 Codex 根据预览继续修改。第二个实战可以做 CSV 数据分析和 HTML 图表报告，顺序是先理解字段、再提结论、最后生成图表，关键数据要人工复核。

和 Codex 说需求时，可以用“目标、背景、输入、输出、约束”五要素。复杂任务先让它复述需求和计划，不要直接动手。

当任务变复杂，可以引入四文档法则：`AGENTS.md` 写项目规则，`PLAN.md` 写计划，`IMPLEMENT.md` 写执行记录，`DOCUMENTATION.md` 写最终说明。

插件、连接器、Skill、MCP 和自动化都很有用，但不是第一步。新手先用内置能力跑通真实任务，等明确需要连接外部账号、浏览器、表格或 PPT 时，再逐步添加。

真正的上手路线是：先熟悉 App，再做低风险对话，再进入演示项目，生成 README 和 HTML 页面，尝试 CSV 报告，学会需求模板和报错排查，最后再碰 Git、Skill、MCP 和自动化。
